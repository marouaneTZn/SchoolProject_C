# University Management System 🎓

A menu-driven command-line application written in C for managing university student records. This project demonstrates foundational C programming concepts including memory management using `structs`, arrays, string manipulation, and standard input/output streams.

## Features

**Currently Implemented:**
- [x] **Add Students:** Register new students with ID, Name, Date of Birth, Department, and General Score.
- [x] **Display Students:** View a cleanly formatted table of all currently enrolled students.

**Roadmap (In Progress):**
- [ ] **Search Students:** Locate a specific student by their unique ID.
- [ ] **Edit Students:** Update a student's department or score.
- [ ] **Delete Students:** Safely remove a student from the active database.
- [ ] **Statistics:** Calculate class averages, pass rates, and total student counts.
- [ ] **Sorting Algorithms:** Display students sorted alphabetically by name or numerically by score.
